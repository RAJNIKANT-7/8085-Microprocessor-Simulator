A virtual simulation of the Intel 8085 microprocessor, built to help students and enthusiasts learn assembly language programming and understand microprocessor architecture without needing physical hardware.

## 🚀 Live Simulator

Click the button above to launch the **8085 Microprocessor Simulator directly in your browser**.

## ✨ Features

- Write and execute 8085 assembly language programs
- Real-time visualization of registers:
  - Accumulator (A)
  - B, C, D, E, H, L registers
- Flag register tracking:
  - Sign
  - Zero
  - Auxiliary Carry
  - Parity
  - Carry
- Memory and Stack Pointer view
- Step-by-step execution / debugging mode
- Support for common 8085 instructions
- Data transfer instructions
- Arithmetic instructions
- Logical instructions
- Branching instructions
- Interactive browser-based simulation

## 💻 Run the Simulator

You don't need to install any software.

**▶ RUN 8085 SIMULATOR**

## 📚 Why this project?

The Intel 8085 is a foundational microprocessor taught in many computer science and electronics curricula.

This simulator provides a hands-on and interactive way to learn:

- 8085 instruction sets
- Assembly language programming
- Registers and flags
- Memory operations
- Stack operations
- Microprocessor concepts

## 🎓 Who is this for?

This project is useful for:

- Students learning the Intel 8085
- Electronics and Computer Science students
- Beginners learning assembly language
- Teachers demonstrating 8085 concepts
- Anyone interested in microprocessor simulation
