# 8085 Microprocessor Simulator

A virtual simulation of the Intel 8085 microprocessor, built to help students and 
enthusiasts learn assembly language programming and understand microprocessor 
architecture without needing physical hardware.

## Features
- Write and execute 8085 assembly language programs
- Real-time visualization of registers (A, B, C, D, E, H, L)
- Flag register tracking (Sign, Zero, Auxiliary Carry, Parity, Carry)
- Memory and stack pointer view
- Step-by-step execution / debugging mode
- Support for common 8085 instructions (data transfer, arithmetic, logical, branching, etc.)

## Why this project?
The 8085 is a foundational microprocessor taught in most computer science and 
electronics curricula. This simulator provides a hands-on, interactive way to 
learn instruction sets and low-level programming concepts.
